1. A function is a group of statements performing a specific task. A function can be reused by the programmer, as many times as he wants. 
2. An f-string lets you put variables or argumentd directly inside strings in Python using an f prefix and curly braces {}.
3. There are two types of functions -
    i. Built-in functions which are already present in Python. eg print(),input(),int() etc.
    ii. User-defined functions which are defined by the user. eg avg(), greet() etc.
4. We can pass an argument to a function using parameters.
5. Return value - A `return` returns a value to a variable. 
6. A default parameter passes the default variable if there are no arguments given for that parameter. 
7. Recursion is when a function calls a smaller copy of itself to solve a big puzzle, step by step, until it reaches the very end. eg  factorial(5) = 5 * factorial(4), now since my function name is 'factorial' it calls itself again but this time its factorial(4) = 4 * factorial(3), This goes on till the base value, which is 1. only then does the functions returns the values which are 1, 1 x 2, 2 x 3, 6 x 4, 24 x 5 which adds up to 120 which is factorial(5).
